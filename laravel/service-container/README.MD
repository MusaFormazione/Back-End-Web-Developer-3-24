# 🧩 Service Container e Dependency Injection (Laravel 12)

Questa sezione raccoglie moduli brevi e pratici sul Service Container di Laravel 12 e la Dependency Injection.
Ogni modulo include: appunti sintetici, esempi collegati al DB Sakila e una breve lista di esercizi.

Indice moduli:
- 01-introduzione — Cos'è il service container e a cosa serve
- 02-esercizio-trading-finance-info — Esercizio guidato su binding, sostituzione implementazioni, cache
- 03-lifecycle-and-bindings — bind (transient) vs singleton vs scoped
- 04-binding-primitives-variadics — binding di tipi primitivi e argomenti variadici
- 05-extend-bindings — decorare i servizi con Container::extend
- 06-service-providers — creare un provider, register/bindings/singletons, metodo boot
- 07-facades — cosa sono, come crearne una custom e come mockarle nei test
